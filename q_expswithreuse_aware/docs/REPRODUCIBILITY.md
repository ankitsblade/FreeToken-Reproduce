## Commands

```bash
# regenerate plans and prompts (deterministic; must reproduce the hashes above)
python3 q_expswithreuse_aware/config/make_plan.py
# unit tests (CPU only)
bash -c 'source scripts/env.sh && experiment_python -m pytest -q -p no:cacheprovider q_expswithreuse_aware/tests'
# full run: waits for WAIT_PID and a free GPU, pauses Judge0, smoke, ablation, analysis
STAMP=20261021T111516Z setsid nohup bash q_expswithreuse_aware/scripts/launch.sh WAIT_PID &
# analysis only
bash -c 'source scripts/env.sh && experiment_python q_expswithreuse_aware/analysis/analyze.py \
  --root q_expswithreuse_aware/results/raw/<stamp> --out q_expswithreuse_aware/results/aggregated/<stamp>'
```

Each GPU step is `EXPERIMENT_OUTPUT_ROOT=<raw> systemd-run --user --scope -p MemorySwapMax=0 bash
scripts/run.sh runtime_q run --plan <plan> --model <ckpt> --gpu 0 --decode <D>`. The run recorder
writes its environment and status record under `results/runs/runtime_q/<stamp>_<id>/`.

## Output layout

| Path | Content |
|---|---|
| `results/raw/<stamp>/runtime_q/results/*_episodes.jsonl` | one row per measured episode (timing, TTFT, text, cache size) |
| `results/raw/<stamp>/runtime_q/results/*_servers.jsonl` | per-server command, environment, geometry, GPU state |
| `results/raw/<stamp>/runtime_q/results/*_lean_qwen.csv` | per-layer decision log (logged round only) |
| `results/raw/<stamp>/runtime_q/logs/serve_*.log` | server logs |
| `results/logs/<stamp>/queue.log` | queue transcript, Judge0 pause/restore, input hashes |
| `results/aggregated/<stamp>/` | analysis tables, plots, generated `REPORT.md`, integration checks, V1 audit |

`raw/` and `logs/` are git-ignored (`results/.gitignore`). Raw evidence must not be deleted.

## Host interventions

The launcher pauses the four Judge0 containers for the GPU part and unpauses them on exit
(standing permission; host-memory headroom for Qwen). The pause list is written to
`results/logs/<stamp>/judge0_paused.txt` while active and removed on restore.
